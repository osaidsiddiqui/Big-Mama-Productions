# 🚀 Quick Start: Deploy to Vercel in 5 Minutes

## Prerequisites
- GitHub account with this repo
- Vercel account (sign up free at vercel.com)

## Deploy Now

### 1️⃣ Commit & Push Code
```bash
git add .
git commit -m "Ready for Vercel deployment"
git push origin main
```

### 2️⃣ Go to Vercel
- Visit [vercel.com/dashboard](https://vercel.com/dashboard)
- Click **"Add New..."** → **"Project"**

### 3️⃣ Import Repository
- Select your GitHub repository
- Click **"Import"**

### 4️⃣ Configure (Auto-detected ✅)
Settings should auto-fill:
- Framework: **Vite**
- Build: **npm run build**
- Output: **dist**

Click **"Deploy"** and wait 1-2 minutes!

## ✅ Done!
Your site is now live at: `https://your-project.vercel.app`

---

## Optional: Add Custom Domain

1. In Vercel Dashboard → Settings → Domains
2. Add your domain (e.g., `bigmamaproductions.com`)
3. Update DNS records at your registrar
4. Wait 24-48 hours for DNS to propagate
